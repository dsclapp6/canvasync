CANVASync

Enter the bridge secret to connect — 64 hex characters, the bridgeSecret value in your data folder's config.json (usually ~/canvas-sync-data/config.json). This is not an install token. The desktop app fills it in automatically.

Copy it to your clipboard:
node -e "console.log(JSON.parse(require('fs').readFileSync(process.env.HOME+'/canvas-sync-data/config.json','utf8')).bridgeSecret)" | tr -d '\n' | pbcopy
